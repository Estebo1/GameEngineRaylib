Raylib Survivor es un juego de acción y supervivencia en 2D en el que tu objetivo es resistir oleadas de enemigos, en donde dispararles te otorga puntos y aveces sueltan municion. Sobrevive hasta alcanzar el puntaje

Se utilizan las siguientes librerias:

Raygui: Utilizada para el diseño de interfaces de usuario, menús y el HUD del juego.

AnimatorForRaylib: Libreria utilizada para poder animar el personaje y el enemigo, cambiando entre estados los cuales cambian de animación

Controles
Movimiento - W, A, S, D o Flechas.

Disparo - Click Izquierdo o Espacio

ESC o P: Pausar el juego.
